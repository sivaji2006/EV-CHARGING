System Architecture & Working Principle

The Smart EV Remote Charging & Auto Cut-Off System integrates an ESP32 microcontroller, a single-channel relay, an analog voltage sensor, and a TP4056 lithium battery charger with a Python Flask REST backend and an interactive web dashboard.

⚡

ESP32 DevKit V1

Central IoT Controller
  • Connectivity: 2.4 GHz Wi-Fi (802.11 b/g/n)
  • HTTP Server: Listening on Port 80 (/on, /off, /status)
  • Relay Pin: GPIO 26 (Active HIGH Output)
  • ADC Pin: GPIO 34 (12-bit Analog Voltage Sensing)
🔌

5V Single-Channel Relay

Power Isolation Gate
  • Control Voltage: 5V DC (Optocoupler isolated)
  • Switching Target: 5V DC TP4056 Input line
  • State: Normally Open (NO) / Common (COM)
  • Safety Feature: Defaults to OPEN / OFF upon boot
🔋

TP4056 Charging Module

Li-ion CC/CV Controller
  • Input Voltage: 5.0V DC (from Relay output)
  • Charging Method: Constant Current / Constant Voltage
  • Max Current: 1.0A charging limit
  • Cell Protection: Overcharge & over-discharge cutoff
⚡

18650 Li-ion Cell

Energy Storage Prototype
  • Nominal Voltage: 3.7V
  • Full-Charge Voltage: 4.20V (100% SOC)
  • Discharge Cut-off: 3.00V (0% SOC)
  • Capacity: 2600 mAh Single Cell
📊

Analog Voltage Sensor

Real-Time Telemetry
  • Principle: 5:1 Precision Resistive Divider
  • Input Range: 0.0V to 5.0V (0.0V to 25V capability)
  • Output: 0.0V to 3.3V safe for ESP32 ADC
  • Telemetry Route: ESP32 pushes to Flask /update_battery
💻

Flask REST Backend

Application & Safety Server
  • Runtime: Python 3 / Flask / Flask-CORS
  • Endpoints: /start, /stop, /status, /update_battery
  • Algorithm: Piecewise Li-ion SOC estimation
  • Protection: Instant relay shutoff when voltage ≥ 4.20V
PROTOTYPE ELECTRICAL SAFETY NOTICE

This prototype operates entirely under low-voltage 5V DC power (5V DC USB adapter powering the relay and TP4056 module to charge a 3.7V single-cell 18650 Li-ion battery). The design demonstrates the software-defined remote charging and autonomous cut-off architecture safely without high-voltage AC mains hazards.
